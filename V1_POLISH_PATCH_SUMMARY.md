# V1 Polish Patch Summary

This patch implements the first code-level foundation for the playable loop:

```text
collect -> craft basics -> place workbench/storage -> craft tools/weapons/capture items -> harvest/fight -> capture Bibbles -> assign Bibbles to workstations
```

## Changed systems

### Shared data model
- Expanded `ItemCatalog` from a few items to a V1 item set:
  - basic materials, berries, ores, ingots, tools, weapons, buckets, cables, pipes
  - workstation kits, building blocks, capture items and Bibble items
- Added category-based item semantics for flexible recipes:
  - tool-head material, handle material, binding material, metal binding, fuel, food, capture items, power/fluid components
- Added `WorkstationCatalog` to centralize workstation/building IDs and station matching.
- Added interaction target/action enums as a base for the generic interaction system.
- Added new tile types for indoor, farmland and Bibble areas.
- Added V1 game-data mirror files under `shared/src/main/resources/game-data`.

### Crafting
- Expanded `CraftingCatalog` with V1 inventory, workbench and machine recipes.
- Recipes now use flexible item categories where possible, e.g. tool head + handle + binding.
- Added early weapons and capture items.
- Added early workstation progression: workbench, storage box, furnace, generator, terminal, pump, quarry, crop farmer, wheels, processor.

### Server gameplay
- Added generic `ACTION` execution:
  - left-click action can harvest tiles or damage/break buildings.
  - broken placeable buildings refund their kit item.
- Added early resource harvesting from tiles:
  - forest/grass/spawn: wood/fiber/berries depending on tool and tile.
  - mountain/wall: stone plus low chances for iron/copper/coal.
  - water with empty bucket creates water bucket.
- Place-building now normalizes build types and uses workstation health defaults.
- Food usage now uses item heal values, not only `BERRY`.
- Bibbles no longer spawn as starters by default.
- Wild Bibbles spawn around map spawn points.
- Added first capture command path: select capture item -> Bibble menu -> `C` capture nearest wild Bibble.

### Client gameplay/UI
- Left click sends generic `ATTACK` action to the server for harvesting/fighting/breaking.
- Crafting menu now filters recipes by available inputs and nearby workstation context.
- Bibble menu now includes capture hint/key.
- Dynamic fallback textures for new items/buildings are generated by type key.

## Important limitations

- Full DB-driven catalog loading is not implemented yet. The new JSON files are planning/migration mirrors.
- Workstations do not yet have real slot inventories, upgrade slots, fluid/power graphs or queues.
- Combat is still very basic and only affects buildings/resource harvesting in this patch.
- Bibble-vs-Bibble/player combat, capture status effects, traps as placed objects and route networks are still next steps.
- Gradle build could not be executed in this environment because the Gradle distribution download is blocked. Shared sources and changed server world classes were syntax-checked with `javac` using available local classes.
